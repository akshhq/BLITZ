# BLITZ static site

This folder is the dependency-free HTML, CSS, and JavaScript version of the BLITZ website. It does not require Node.js, React, Next.js, GSAP, or a build command.

- Open `index.html` directly in a browser, or serve this folder with any static-file host.
- `styles.css` contains the complete visual system and responsive layout.
- `script.js` contains the menu, scroll-linked logo, native scroll reveals, horizontal rails, expandable cards, and dynamic section rendering.
- `assets/` is a local copy of the site assets used by the static page.
